풀림 안내

우클릭 · 글자 선택(드래그) · 복사를 막아 둔 사이트를 다시 쓸 수 있게 풀어 줍니다.

풀림이 켜졌어요

이제 따로 할 일은 없어요. 우클릭이나 복사가 막힌 사이트에 들어가도 그냥 평소처럼 쓰면 됩니다. 도구 막대의 퍼즐 조각 아이콘을 눌러 풀림 옆 핀을 누르면 아이콘이 늘 보여서 편해요.

브라우저에 풀림 추가하기 (브라우저마다 한 번만)

설치 프로그램이 풀림을 아래 폴더에 넣어 두었어요. 쓰는 브라우저마다 이 폴더를 한 번 불러오면, 그다음부터는 자동으로 업데이트돼요.

%LOCALAPPDATA%\Pullim\extension

폴더 선택 창 위쪽 주소 칸에 그대로 붙여넣고(Ctrl+V) Enter → 폴더 선택을 누르면 돼요.

크롬

  1. 주소창에 chrome://extensions 입력
  2. 오른쪽 위 개발자 모드 켜기
  3. 왼쪽 위 압축 해제된 항목 로드(또는 '압축해제된 확장 프로그램을 로드합니다') 누르기
  4. 폴더 경로 붙여넣기 → 폴더 선택

크롬은 개발자 모드가 켜져 있어야 풀림이 동작해요. 꺼 두면 풀림도 꺼집니다.

엣지

  1. 주소창에 edge://extensions 입력
  2. 왼쪽 아래(창이 넓으면 위) 개발자 모드 켜기
  3. 압축을 푼 항목 로드(영어 화면은 Load unpacked) 누르기
  4. 폴더 경로 붙여넣기 → 폴더 선택

엣지는 시작할 때마다 개발자 모드 확장을 끄라는 알림을 띄워요. 알림 오른쪽 위 X 로 닫으세요. 끄기를 누르면 풀림이 꺼져요(그땐 edge://extensions 에서 다시 켜면 됩니다).

네이버 웨일

  1. 주소창에 whale://extensions 입력
  2. 화면 아래쪽 개발자 모드 켜기
  3. 압축해제된 확장 앱 설치 누르기
  4. 폴더 경로 붙여넣기 → 폴더 선택

브라우저마다 처음 한 번 "풀림이 켜졌어요" 안내 탭이 열리면 끝난 거예요.

쓰는 법

  • 그냥 쓰면 돼요. 막혀 있던 우클릭 메뉴, 드래그로 글자 고르기, Ctrl+C 복사가 모든 사이트에서 다시 됩니다.
  • 아이콘 글자 — 아무 글자 없음: 켜짐 · 끔 이 사이트에서 꺼 둠 · 강 강력 모드 · ! 강력 모드가 필요해 보임
  • 그래도 안 풀리면 아이콘을 눌러 강력 모드를 켜세요. 마우스 누름을 막거나, 고른 글자를 바로 지우거나, 투명한 판을 덮어 둔 사이트까지 풀어요.
  • 사이트 기능이 이상해지면 아이콘을 눌러 이 사이트 스위치를 끄세요. 그 사이트는 원래대로 돌아가요.
  • 사이트 자체 우클릭 메뉴가 필요하면 Shift 를 누른 채 우클릭하세요.
  • 구글 문서 · 지도 · 유튜브처럼 자체 메뉴를 쓰는 웹 앱은 처음부터 꺼 두었어요. 필요하면 아이콘에서 켤 수 있어요.
  • 입력 칸 안에서는 사이트가 하는 대로 둡니다(비밀번호 관리자 · 글쓰기 편집기가 망가지지 않게).

자동 업데이트

설치 프로그램으로 설치했다면 윈도우의 풀림 업데이트 도우미가 로그인할 때와 3시간마다 GitHub 에서 새 버전을 확인해요. 새 버전이 있으면 받아서(SHA-256 확인) 확장 폴더를 바꿔 두고, 브라우저 속 풀림은 10분 안에 그걸 알아채 스스로 다시 불러와요. 브라우저를 다시 켤 필요가 없어요.

바로 확인하려면 시작 메뉴 → 풀림 → 풀림 업데이트 확인. 기록은 %LOCALAPPDATA%\Pullim\helper.log 에 남아요.

자주 묻는 것

강력 모드로도 안 풀려요

글자를 그림이나 캔버스로 그려 둔 페이지, 글자를 뒤섞은 글꼴로 보여 주는 페이지는 확장 프로그램으로 풀 수 없어요. 그런 곳은 화면 캡처가 방법이에요.

풀림을 지우고 싶어요

윈도우 설정 → 앱 → 설치된 앱에서 풀림을 제거하고, 각 브라우저의 확장 프로그램 페이지에서 풀림의 삭제를 누르세요.

설치 파일을 열 때 "Windows의 PC 보호" 창이 떠요

개인이 만든 프로그램이라 코드 서명이 없어서 나오는 창이에요. 추가 정보 → 실행을 누르면 설치돼요. 관리자 권한은 필요 없어요.

무엇을 가져가거나 보내나요?

아무것도 보내지 않아요. 풀림이 인터넷에 접속하는 건 GitHub 에서 새 버전 정보(latest.json)를 읽을 때뿐이에요. 코드는 모두 GitHub 에 공개돼 있어요.

복사한 글과 그림의 저작권은 원래 만든 사람에게 있어요. 퍼 갈 때는 출처를 밝히고 허락된 범위에서 써 주세요.
